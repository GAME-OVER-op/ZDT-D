# ZDT Chat для root-версии

Root-сборки ZDT-D предлагают ZDT Chat после завершения первоначальной настройки и
появления главного экрана. Предложение не скачивает ничего до согласия; отказ
сохраняется. Установка проходит через стандартный установщик Android, без root.
На устройствах без поддержки ARM64 предложение не показывается. Non-root-версия
ZDT-D не содержит этой точки входа.

После установки лаунчер предлагает создать ярлык. Пока ярлык не закреплён, кнопка
«Чаты» перед «Логами» открывает чат; длинное нажатие повторяет запрос на ярлык.
Чат работает в своём процессе, с собственными разрешениями Android.

## Публикация

- `.github/chat-plugin.ref` должен указывать на опубликованный, проверенный коммит
  ветки `plugin` репозитория `ZDT-D_chat`.
- Для сборки плагина в Actions ZDT-D требуются `CHAT_COMMUNITY_ROOM_ID` и
  `CHAT_COMMUNITY_RENDEZVOUS_TOPIC` с теми же значениями, что у самостоятельного
  чата. Без этих настроек старые артефакты не заменяются.
- Исходники плагина собираются без ключа. Отдельное задание подписывает готовый APK
  существующим релизным ключом ZDT-D и проверяет сертификат, пакет и ARM64-библиотеки.
- `Technical_Assets` получает `zdt-d-chat-plugin.apk` и `chat-plugin.json`. ZDT-D
  сверяет размер и SHA-256 APK, версию, пакет и сертификат до запуска установщика.
  Чат с другим сертификатом программа не удаляет и не заменяет.

## Проверка на телефоне

На чистом root-устройстве проверить отказ от предложения и установку (раздельно),
отказ от ярлыка, повтор запроса по удержанию кнопки и запуск из закреплённого
ярлыка. На двух устройствах проверить обновление счётчика пиров и остановку сети
после отказа Android в фоновой работе. На устройстве с тестовым APK другой
подписи проверить, что предложение не удаляет локальные данные.
